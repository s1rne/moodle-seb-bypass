# Папка для публикации на Хабр

Всё для статьи «Как я сдавал английский через самописный бэкдор в Safe Exam Browser».

## Что тут лежит

| Файл | Что это |
|---|---|
| `article.md` | Текст статьи в Markdown. Новый редактор Хабра принимает Markdown как есть: создайте черновик, вставьте содержимое файла. |
| `article.html` | Та же статья в HTML с оформлением. Пригодится для старого HTML-редактора Хабра или для локального просмотра (откройте в браузере). |
| `fig1_protocol.png` | Схема: браузер, mitmproxy, Moodle и пять шагов проверки. |
| `fig2_configkey.png` | Схема: четыре шага от XML-конфига до ConfigKey. |
| `fig3_cookie.png` | Схема: откуда взять MoodleSession в DevTools. |
| `fig4_score.png` | График: баллы по всем квизам курса, 772 из 780. |
| `fig*.py` | Исходники картинок (matplotlib). Правите и запускаете `python3 figX_....py`, картинка перегенерируется. |

## Как загрузить на Хабр

1. Создайте черновик: [habr.com/ru/articles/drafts/](https://habr.com/ru/articles/drafts/new/).
2. Вставьте текст из `article.md`. В новом редакторе Хабра Markdown принимается нативно.
3. Картинки загрузите вручную через кнопку вставки изображения: `fig1_protocol.png`, `fig2_configkey.png`, `fig3_cookie.png`, `fig4_score.png` в тех местах, где они стоят в тексте. После загрузки Хабр заменит локальные пути на свои URL.
4. Проверьте предпросмотр, выберите хабы (Python, Информационная безопасность, Reverse Engineering, Образование) и отправляйте.

## Перед публикацией, две минуты проверки

- Ссылка на репозиторий в статье ведёт на `github.com/s1rne/moodle-seb-bypass`, живая ли.
- В тексте упоминаются 98.71% и 22-е место из 372: если данные обновились, поправьте.
- Название теста «Midterm»/«Final» и формулировки про университет обезличены, но если хотите, добавьте конкретику.
- Скриншотов реального Moodle в статье нет специально: только схемы, сгенерированные matplotlib, без данных студентов.
